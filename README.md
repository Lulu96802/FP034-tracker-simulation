# FP034 Livelihood Tracker — SIMULATION

Demonstration copy of the FP034 / PIMS-5711 livelihood group tracker with **hypothetical data only**.
The whole project period (Oct 2026 – Aug 2027) can be played on the timeline or picked in the "As of" calendar.

- `overview.html` — all districts
- `districts/mitooma.html` — Mitooma district (the only district with full simulated data)

The real tracker lives in the separate `FP034-tracker` repository.
